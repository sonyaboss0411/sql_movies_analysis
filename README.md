# sql_movies_analysis
SQL-анализ БД фильмов (200 строк) для оценки окупаемости. Мы спроектировали нормализованную БД из 6 таблиц и проверили гипотезы: доказали, что бюджет не гарантирует успех, а по оценкам критиков лидирует Crime (9.5), по числу релизов — Animation (16). Результаты визуализированы в Excel.
